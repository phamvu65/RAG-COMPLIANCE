# Graph RAG Compliance

Compliance checking for business process event logs against regulatory text, using a
knowledge graph (Neo4j) and LLM-based Retrieval-Augmented Generation (RAG) to explain
violations in plain language.

The reference case study uses the **BPI Challenge 2017** loan application event log
checked against the EU **Consumer Credit Directive 2008/48/EC**.

## How it works

1. **Event log ingestion** — parse the raw XES event log, clean and standardize it into
   per-case traces.
2. **Knowledge graph construction** — load event traces and regulation clauses
   (activities, sequences, conditions, roles) into Neo4j as a linked graph.
3. **Conformance checking** — align traces against the regulation graph and process
   model (via `pm4py`) to detect skipped steps, out-of-order activities, temporal
   violations, and other rule breaks.
4. **Graph RAG explanation** — retrieve the relevant regulation subgraph for each
   violation and use an LLM (OpenAI / Anthropic) to generate a human-readable
   compliance report.
5. **Baseline comparison** — a token-based replay baseline (`pm4py`) is included to
   compare against the graph-based approach.

## Project structure

```
src/
  event_log/         Ingest, clean, and build traces from the raw XES event log
    ingest.py           One-shot XES ingestion
    preprocessor.py      Column standardization, filtering, deduplication, validation
    trace_builder.py     Build per-case traces and Cypher queries
    neo4j_loader.py       Load traces into Neo4j
  knowledge_graph/
    regulation_loader.py Load regulation JSON (activities/sequences/conditions/roles) into Neo4j
  compliance/
    trace_fetcher.py     Fetch traces back from Neo4j
    regulation_fetcher.py Fetch regulation subgraphs from Neo4j
    checkers.py           Rule-based violation checks (skip/order/temporal/etc.)
    alignment_engine.py   Align traces against the regulation graph
    violation_report.py   Violation/severity data model
  graph_rag/
    retriever.py          Graph RAG retrieval of relevant regulation context
    explainer.py           LLM-based violation explanation
    report_generator.py   Compliance report assembly and formatting

notebooks/            End-to-end pipeline, run in order (00 -> 07)
data/
  raw/                Source XES log and regulation SOP/JSON (gitignored)
  processed/          Generated traces, compliance results, reports (gitignored)
patch_regulation_json.py  One-off script to backfill `linked_activities` on regulation conditions
```

## Notebooks

| Notebook | Purpose | Needs Neo4j |
|---|---|---|
| `00_inspect_dataset.ipynb` | Inspect the raw event log and Neo4j connectivity | Yes |
| `01_explore_eventlog.ipynb` / `01_preprocess.ipynb` | Explore and preprocess the event log | No |
| `02_load_traces.ipynb` | Load processed traces into Neo4j | Yes |
| `03_build_regulation_graph.ipynb` / `03_sop_analysis.ipynb` | Build the regulation knowledge graph | Yes |
| `04_alignment.ipynb` | Align traces against the regulation graph, detect violations | Yes |
| `05_embed_regulation.ipynb` | Embed regulation text for retrieval | Yes |
| `06_graph_rag_explain.ipynb` | Retrieve context and generate LLM explanations/reports | Yes |
| `07_baseline_token_replay.ipynb` | Token-based replay baseline for comparison | No |

## Setup

1. Create/activate a virtual environment and install dependencies:
   ```
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Start a local Neo4j instance (e.g. via Neo4j Desktop) on the default Bolt port.
3. Create a `.env` file in the project root:
   ```
   NEO4J_URI=bolt://localhost:7687
   NEO4J_USERNAME=neo4j
   NEO4J_PASSWORD=<your-password>
   OPENAI_API_KEY=<your-key>
   ANTHROPIC_API_KEY=<your-key>
   ```
4. Verify the Neo4j connection:
   ```
   python test_connection.py
   ```
5. Run the notebooks in `notebooks/` in numeric order.

## Data

Raw and processed data files live under `data/` and are gitignored — they must be
provided locally (BPI 2017 XES log and regulation SOP/JSON) or regenerated by running
the notebooks in order.
